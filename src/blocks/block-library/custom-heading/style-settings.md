# カスタム見出しのスタイル設定仕様

更新日: 2026-08-21

## 適用対象

カスタム見出しを次の3つの対象に分け、スタイルを混在させない。

-   メインテキスト: `.ystdb-custom-heading`を付けた見出しタグ
-   サブテキスト: `.ystdb-custom-heading-sub`を付けた`p`タグ
-   見出しグループ: `.ystdb-custom-heading-group`を付けた`hgroup`タグ

メインテキストはWordPressコアのBlock Supportsを正本にする。サブテキストと見出しグループは、スタイルコピーの対象になる`style`属性内の独自領域へ保存する。

## メインテキスト

WordPressコアのパネルを利用し、Block Supportsが生成したクラスとインラインスタイルを見出しタグだけへ適用する。

-   色: 文字色、背景色、グラデーション、リンク色
-   タイポグラフィ: フォントサイズ、フォント、外観、行の高さ、文字間隔、装飾、大文字小文字、文字揃え、書字方向
-   余白: パディングは4方向、マージンは上下のみ
-   枠線: 枠線、角丸

背景、枠線、角丸は初期表示せず、WordPressコアの`+`メニューから追加する。「テキストを合わせる」はサポートしない。

## サブテキスト

サブテキストを使用している場合だけ、次のToolsPanelをスタイルグループへ表示する。

-   サブテキスト（文字）: 色、フォントサイズ、フォント、外観、行の高さ、文字間隔、装飾、大文字小文字
-   サブテキスト（背景）: 色、グラデーション
-   サブテキスト（枠線）: 枠線、角丸
-   サブテキスト（余白）: パディング、マージン

色とフォントサイズは初期表示する。それ以外の項目は値が設定済みの場合だけ表示し、未設定時は`+`メニューから追加する。背景の色とグラデーションは初期表示しない。余白はパディング、マージンとも4方向を指定できる。

## 見出しグループ

サブテキストを使用して`hgroup`が存在する場合だけ、次のToolsPanelをスタイルグループへ表示する。

-   見出しグループ（余白）: パディング、マージン
-   見出しグループ（背景）: 色、グラデーション
-   見出しグループ（枠線）: 枠線、角丸

背景の色とグラデーションは初期表示しない。見出しグループはブロックのルート要素になるため、マージンは上下だけ、パディングは4方向を指定できる。

## 保存先

```json
{
	"style": {
		"ystdb": {
			"customHeading": {
				"sub": {
					"typography": {},
					"color": {},
					"border": {},
					"spacing": {}
				},
				"group": {
					"color": {},
					"border": {},
					"spacing": {}
				}
			}
		}
	}
}
```

空になったオブジェクトは保存しない。`hasSubText`をOFFにしても設定値は削除せず、再度ONにしたときに復元する。

## スタイル出力

サブテキストと見出しグループの独自設定も、メインテキストと同じBlock Supportsアダプターへ渡す。タイポグラフィ、色、余白、枠線のCSS変換をブロック側で個別実装せず、編集画面と保存HTMLで同じ結果を使う。

プリセット値は`var:preset|...`形式で保持し、出力時にWordPressのスタイルエンジンがCSS変数へ変換する。これによりテーマのプリセット変更とスタイルコピーの両方へ対応する。

## リセット

各ToolsPanelの「すべてリセット」は、そのパネルが管理するスタイル区分だけを削除する。個別項目の解除では同じ対象の別項目を維持する。サブテキストの使用設定や入力内容はスタイルのリセット対象に含めない。
